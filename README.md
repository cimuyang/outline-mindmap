# outline-mindmap
Obsidian plugin: Minimalist and intuitive outline mind mapping using only the purest Markdown syntax, leaving no redundant code in your note files. Click to locate instantly, featuring real-time bi-directional synchronization between the mind map and notes. Obsidian 插件：极简直观的思维导图，仅使用最纯粹的 Markdown 语法，笔记文件中不会留下任何冗余代码。点击即可快速定位，思维导图和笔记之间实现实时双向同步。
